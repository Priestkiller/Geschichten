# Figurenkatalog 0.3.0

Der enthaltene Katalog umfasst 50 erwachsene Figuren: zehn pro vorhandener Kategorie, jeweils fünf weibliche und fünf männliche Figuren. Die bisherigen 20 Profile bleiben erhalten. 30 neue Profile bringen eigene Persönlichkeiten, Ziele, Einstiege, Porträts und je vier ausdrücklich als Startvorgaben gekennzeichnete Notizen mit.

| Kategorie | Weibliche Figuren | Männliche Figuren |
| --- | --- | --- |
| Nordische Fantasy | Runa, Astrid, Sigrid, Liv, Solveig | Eirik, Torben, Halvard, Bjarke, Yngvar |
| Fantasy | Elara, Aelwyn, Nyra, Sylwen, Thora | Borin, Kael, Varen, Orin, Maelis |
| Krimi | Johanna, Vera, Nora, Ines, Hedda | Leon, Cem, Anton, Kaspar, Malik |
| Science-Fiction | Mira, Sana, Lyra, Keira, Ada | Tarek, Ivo, Noam, Rohan, Silas |
| Kreaturen | Seris, Nessa, Pyra, Thalora, Veshra | Vaelgor, Fenrik, Soryn, Korr, Aruun |

Die Körperformen der Kreaturen gehören zum jeweiligen Profil: Thalora bleibt eine Meeresschildkröte; Veshra besitzt einen Löwenkörper, ein reifes menschliches Gesicht und gefiederte Schwingen. Ivo ist ein selbstständig lebender erwachsener Android. Alter, Persönlichkeit und Grenzen stehen im aktiven Profiltext.

Einige neue erwachsene Figuren tragen freizügigere Outfits: Eirik ein offenes Hemd, Liv ein Reiseoberteil mit tiefem Ausschnitt und Malik ein sportliches Oberteil unter seiner offenen Jacke. Maelis trägt eine offene Weste und ein Hemd mit offenem Kragen; Keira eine offene Pilotenjacke über einem schlichten Shirt. Die Kleidung allein legt keine Beziehung oder Handlung der Spielerfigur fest.

Beim Wechsel von Datenbankversion 2 auf 3 werden nur fehlende Figurenkennungen eingefügt. Bestehende Profile, eigene Bearbeitungen, eigene Figuren, Reihenfolge, Geschichten, Nachrichten, Zusammenfassungen und Erinnerungen werden nicht überschrieben. Neue Einträge werden hinten angehängt. Bei einer Kennungskollision behält die bestehende Figur Vorrang; daher kann die sichtbare Standardverteilung nach eigenen Bearbeitungen von der obigen Tabelle abweichen.

Neue Geschichten erhalten die passenden Startvorgaben. Laufende Geschichten behalten ihre eigenen gespeicherten Notizen. Nach einer selbst bearbeiteten Einstiegsszene werden die ursprünglichen Orts- und Aufgabenangaben nicht erneut eingesetzt.

Die Porträts entstehen mit dem eingebauten Imagegen-Werkzeug, je Figur in einem eigenen Aufruf. Die vollständigen Prompts stehen in [artwork-0.3.0/prompts.json](artwork-0.3.0/prompts.json); die App-Dateien liegen unter `app/src/main/res/drawable-nodpi/portrait_<kennung>.png`.
